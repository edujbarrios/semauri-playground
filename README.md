# Semauri Playground

Editor web de código `.suri` y consola de ejecución basados en el compilador oficial de [Semauri](https://github.com/edujbarrios/semauri).

Aplicación de código abierto diseñada para **Vercel**. El código, el editor y la integración del compilador se encuentran en este repositorio.

La implementación se publicará en una rama de desarrollo y se revisará mediante una pull request.
